## 🚀 શરૂ કરવું

### ઇન્સ્ટલેશન

1. **ડાઉનલોડ કરો અથવા ક્લોન કરો**
```bash
git clone https://github.com/RAVJJ/gujarati-dost.git
cd gujarati-dost
```

2. **ફાઇલો ખોલો**
- `index.html` ને તમારા બ્રાઉझર માં ખોલો
- અથવા લાઇવ સર્વર સાથે:

```bash
# Python 3 સાથે
python -m http.server 8000

# Node.js સાથે
npx http-server
```

3. **બ્રાઉઝ કરો**
```
http://localhost:8000
```
